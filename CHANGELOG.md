# Changelog

All notable changes to WalkPace will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Conventional Commits](https://www.conventionalcommits.org/).

## [1.0.0] — 2025-XX-XX

### Added
- Interval timer with FAST/SLOW phases (3min/3min x 5 rounds)
- Animated SVG progress ring with color-coded phases
- Audio feedback (beep on interval switch, works with locked screen)
- Haptic feedback on interval switch
- Session summary with duration, rounds, calories, streak
- History & stats (total walks, time, calories, streak)
- Calendar heatmap (monthly view with active days)
- 25 achievement badges (walks, streaks, minutes, calories)
- Badge unlock celebration modal
- Settings (sound, vibration, warm-up/cool-down, accessibility)
- Anonymous auth (automatic, invisible to user)
- Sign in with Apple (links to anonymous account)
- Cloud sync (offline-first, push on write, pull on foreground)
- Onboarding carousel with walking frequency calibration
- Dark mode (follows system preference)
- 53 languages with auto-detection
- Sentry crash reporting
